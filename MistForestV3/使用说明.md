# 雾隐之森 · 四职业地图更新版

Windows 双人隐藏位置策略游戏。解压完整文件夹，双击 `MistForest.exe` 即可运行，无需安装编译器。源代码随包提供，每个非空代码行附中文注释。

## 快速开始

1. 选择 **3×3 无限侦察**、**4×4 四职业** 或 **5×5 四职业**，再选择人机、同机双人或双人联机。
2. 职业版先选择角色，再点击棋盘上的秘密起点。双方可以选择相同职业、站在同一格；开局后职业公开，位置隐藏。
3. 点击右侧行动方式，再点击目标格，将动作按顺序加入计划。侦察时，点击所需行或列内的格子；“原地等待”和“指定跟随”可直接加入计划。
4. 组合行动需依次添加，例如座狼“移动 → 攻击 → 移动”。棋盘显示计划结束时的预览位置，可“撤销一步”。点击“确认本回合”或按 Enter 执行。
5. 同机双人看完私人结果后，点击“隐藏视角 · 交给下一位”，再交接电脑。联机时双方各自操作自己的窗口。

## 三张地图

**3×3 侦察版：** 每回合移动一格或原地等待、攻击距离不超过1的一格、侦察一行或一列，三类行动选一项。侦察不限次数，但每次消耗回合。无侦察原版已从本版本菜单移除。

**4×4 职业版：** 格子按从左到右、从上到下编号1–16，全部16格均可进入，没有地图障碍；沿用下方四职业、无限侦察和联机规则。

**5×5 职业版：** 格子按从左到右、从上到下编号1–25。四个角格（1、5、21、25）以及中心13号格整局禁止进入或停留，因此有20个可用格。秘密起点、普通移动、冲刺路径和复制移动都受此限制；禁入格也不能选为攻击目标。

距离是水平距离与竖直距离之和，例如（1，1）到（2，3）距离为3。所有移动沿上下左右进行。攻击允许选择自身格，命中立即获胜；若命中发生在组合行动中，后续步骤不再执行。5×5地图上，攻击起点格中心到目标格中心的线段只要与中心障碍方格相交，包含碰到边或角，就不能攻击。4×4地图没有该遮挡。侦察行列不受攻击遮挡影响。

| 角色 | 射程 | 每回合能力 |
| --- | --- | --- |
| 狙击手 | 3 | 移动一格或等待、攻击、侦察，选一项。 |
| 座狼 | 1 | 普通移动合计0–2步，另可攻击或侦察一次；移动可分配在主行动前后。 |
| 白墨 | 1 | 普通移动0–1步后可攻击或侦察一次；行动最前或最后可额外冲刺一次。 |
| 随影 | 2 | 移动或等待、攻击、侦察、指定跟随、移动带动，选一项。 |

座狼和白墨可以只移动、不攻击。所有职业均可不限次数侦察，每回合最多一次，不能同回合攻击并侦察。原地等待会占用一次普通移动操作。每局最多80个完整回合，单个组合回合中的子动作不分别计数；到达上限仍未命中则记为未决。

### 白墨冲刺

- 目标与当前位置的距离必须**恰好为2**，沿两步合法路径到达；不能冲刺一步或留在原地，也不能经过禁入格。
- 斜向目标若有两条合法最短路径，程序固定先竖直后水平；若该路径经过障碍，采用另一条合法路径。
- 冲刺只能放在整个计划最前或最后，不能夹在普通移动与攻击之间。
- 使用后，接下来的**两个自己的回合**不能冲刺，第三个自己的回合恢复。普通移动预算与冲刺分开计算。

### 随影的两种跟随

- **指定跟随：** 消耗随影当前回合。随后在敌方下一回合，随影从自己的位置复制敌方每一步位移，包括白墨冲刺的两步；不消耗随影额外回合。敌方该回合结束后标记失效。
- **移动带动：** 随影在自己的回合移动一格或等待，同时让对手复制相同位移。它是一项完整行动，不能同时攻击。
- 复制位移会越界或进入禁入格（5×5的四角与中心）时，仅跳过该步，后续步骤继续处理。被阻挡的玩家收到私人提示，另一方不会直接看到该提示。复制移动不会递归触发新的跟随。

## 信息与复盘

公开记录展示动作类型和攻击格；移动与原地等待共用提示，不公开移动方向、起止坐标。侦察的行列公开，结果只给侦察者。跟随受阻报告也只给受影响者。

可开启推理辅助，浅绿色表示仍未排除的敌方位置，**不是概率或必然所在格**。复杂组合移动后，辅助可能保守地保留额外候选。侦察结果附取得时的回合号，只代表当时情况。

人机提供进攻、隐蔽、灵活三种启发式策略，不代表最优博弈策略。同机提供交接遮挡及系列赛。结束后可按完整回合复盘双方位置和实际执行的动作，并导出到程序旁的 `replays` 文件夹；复盘不是子动作动画。

## 双人联机

双方均需运行本次**地图更新版**；它使用新版协议，不兼容更新前的四职业客户端，以避免双方地图规则不一致。

1. 房主选择地图并进入联机页面，填写端口（默认 **39091**），创建房间。
2. 另一方填写房主可达的 **IPv4 地址**和相应端口，加入房间。
3. 双方选择职业和秘密起点后自动开局；重赛由房主发起，并交换先手。

同一局域网使用房主的局域网 IPv4。不同网络可使用 Radmin VPN 等虚拟局域网，双方加入同一虚拟网络，填写房主在其中的 IPv4；也可以自行配置公网 TCP 端口映射。Windows 防火墙需要允许程序在实际使用的网络上收发连接。

本版**仅接受 IPv4 地址**，不能直接填写 `1035e090d8d1f8303bcb73098e0de583.mct.net` 这类域名，也不内置公网中继或自动穿透。房主承担裁判职责，保存完整局面；普通客机只接收自己的位置和允许获得的信息，赛后才取得完整复盘。适合可信朋友或课堂对战，不具备防房主作弊能力。

## 源代码与编译

- `app.cpp`：Windows 窗口、回合计划、同机交接、联机操作、课堂与复盘界面。
- `game.hpp` / `game.cpp`：距离和遮挡、职业规则、推理候选、裁判与人机策略。
- `network.hpp` / `network.cpp`：TCP 会话及双方视图同步。
- `lessons.hpp`：三个3×3推理练习。

使用支持 C++17 的 MinGW-w64，在本文件夹中编译：

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Werror -pedantic -static -municode -mwindows app.cpp game.cpp network.cpp -lgdi32 -luser32 -lws2_32 -o MistForest.exe
```

本次按要求采用精简验证：检查5×5禁入格在开局、移动、冲刺、跟随及候选集合中的限制，4×4四职业与侦察，以及本机真实 TCP 会话的地图同步、复盘与重赛；另检查地图选择和离屏绘制的界面。此前版本已完成300局规则模拟，本次未重复大批量模拟。**尚未在两台实体电脑之间或跨公网环境实测**，实际连通性取决于双方网络配置。
