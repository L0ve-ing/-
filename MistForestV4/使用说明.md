# 雾隐之森 · 地图 DIY 版

Windows 回合制隐藏位置策略游戏。解压完整文件夹后运行 `MistForest.exe`。本版新增可保存、加载和联机同步的5×5地图编辑器，并从4×4、5×5全部职业对战中移除侦察。3×3无限侦察版、推理课堂与赛后复盘继续保留。

## 设计并保存地图

1. 在大厅点击 **地图 DIY · 编辑 / 保存**。首次进入载入原有四角及中心方墙布局；全部25格都可以改成空地。
2. 选择工具并点击左侧地图：**空地、方形墙、湖泊**作用于格子；**线形墙**作用于格子边上的虚线，再次点击同一条边可移除。
3. **橡皮擦**可以清除整格地形或线形墙。**撤销修改**恢复最近一步，最多保存100步历史。**全空地图**清空全部地形和边墙，**恢复默认**还原四角及中心方墙；两种操作均可撤销。
4. 点击 **保存到本地…**，选择位置和文件名，保存为 `.mistmap` 文件。默认目录是程序旁的 `maps`；中文文件名可用。可保存多张地图，也可把文件分享给朋友。
5. 点击 **打开地图…** 可载入已有文件。文件损坏、格式错误或没有任何空地时会提示失败，并保留正在编辑的地图。
6. 点击 **使用此地图 · 返回大厅**，再选择人机、双人交接或联机。保存文件与应用地图是两个独立操作；重新打开程序后，用“打开地图”加载，再点击“使用此地图”。

大厅的 **使用 DIY 地图** 会选中最近一次应用的地图；点击 **5×5 四职业** 则使用默认布局。当前草稿在程序未退出时保留，退出前请保存需要保留的修改。

随包提供 `maps/全空地图.mistmap`、`maps/默认五格地图.mistmap` 与 `maps/湖畔与矮墙.mistmap` 三张示例地图。进入编辑器点击“打开地图”即可使用。

## 地形规则

| 地形 | 站立与移动 | 攻击 |
| --- | --- | --- |
| 空地 | 可以进入和停留，双方允许同格 | 可选为目标，正常判定命中 |
| 方形墙 | 占据一整格，不能进入、停留或穿过 | 阻挡攻击，不可选为攻击目标 |
| 线形墙 | 占据一条格边，两侧格子仍可站人，但不能跨过该边 | 攻击连线碰到该线段即被阻挡 |
| 湖泊 | 占据一整格，不能进入、停留或穿过 | 不遮挡攻击；可以射击湖泊格，但其中不可能有人 |

距离仍为水平距离与竖直距离之和。攻击遮挡使用双方格子中心之间的直线判断；碰到方墙的边、角，或线形墙端点，也视为被挡住。湖泊不会增加攻击距离。

普通移动、白墨冲刺的每一步、随影的跟随和带动都遵守实际地形。冲刺不会越过墙或湖泊。跟随受阻时跳过该步，继续处理后续步，并只向受影响的玩家显示提示。

地图至少保留一格空地即可保存和使用，因为允许双方同格开局。编辑器不限制地图连通性，也不自动保证职业平衡；互不相通且攻击无法穿越的区域可能导致未决局。

## 地图与角色

**3×3侦察版：** 地图全部可进入，无职业技能。每回合从移动或等待、攻击、侦察一行或一列中选一项；攻击射程1，侦察不限次数，每次占用回合。

**4×4职业版：** 全部16格可进入，无地形编辑，已移除侦察。

**5×5职业版：** 可选择默认地图或DIY地图。默认地图1、5、13、21、25号为方墙；DIY可自由改变全部格子和横竖格边。已移除侦察。

| 角色 | 射程 | 每回合能力 |
| --- | --- | --- |
| 狙击手 | 3 | 移动一格或原地等待，或攻击一次。 |
| 座狼 | 1 | 普通移动合计0–2步，另可攻击一次；移动可安排在攻击前后。 |
| 白墨 | 1 | 普通移动0–1步后可攻击一次；行动最前或最后可额外冲刺一次。 |
| 随影 | 2 | 移动或等待、攻击、指定跟随、移动带动，选一项。 |

白墨冲刺的目标与当前位置必须恰好相距2格，经两步合法路径到达。两条最短路径均可行时优先竖直方向；否则选另一条合法路径。冲刺只能放在回合计划最前或最后。使用后的两个自己的回合不可再次冲刺，第三个自己的回合恢复。

随影的 **指定跟随** 消耗当前回合，随后在敌方下一回合自动复制敌方各步移动，包括冲刺。**移动带动** 则在随影自己移动一格或等待时，让敌方复制相同位移。复制移动不递归触发新的跟随，也不额外消耗被带动者回合。

## 对战操作与复盘

双方秘密选择职业与起点，准备完成后职业公开，位置隐藏。点击行动按钮，再点击目标格，将动作按顺序加入计划；用“撤销一步”或“清空计划”修改。点击“确认本回合”或按 Enter 后才实际执行。命中立即获胜，尚未执行的后续步骤取消。

原地等待合法。公开记录不区分普通移动与等待，也不公开移动方向、终点。地图地形对双方公开。推理辅助显示仍未排除的候选格，不代表概率；复杂组合移动后可能保守地保留额外候选。

每局最多80个双方合计的完整回合，子动作不单独计数；达到上限仍未命中则为未决。本地双人通过遮罩交接视角；人机提供三种启发式风格；本地可选择系列赛。赛后可按完整回合查看双方位置、地形与候选集合，也可导出到程序旁的 `replays` 文件夹；记录包含该局地图编码。

## 双人联机与自定义地图

双方必须使用本次 **地图 DIY 版**，旧版本不能混连。

1. 房主先在编辑器中打开或制作地图，点击“使用此地图”，再进入联机页面创建房间。默认 TCP 端口为 **39091**。
2. 对方填写房主可达的 **IPv4地址**与端口加入。
3. 地图在选择职业和起点前自动同步给对方，无需对方提前安装同一地图文件。对局开始后不能修改该局地形。
4. 房主发起重赛时沿用同一地图并交换先手；更换地图需回大厅重新创建房间。赛后复盘保留当局实际地图。

异地仍需可互通的虚拟局域网或公网端口映射，程序不内置公网中继、自动穿透或域名连接。房主承担可信裁判职责，不具备防房主作弊能力。Windows防火墙需允许程序在实际使用的网络上通信。

## 源码与验证

源码采用 C++17，每个非空代码行附中文注释。

- `app.cpp`：地图编辑器、对战界面、交接遮罩与复盘。
- `game.hpp` / `game.cpp`：地图、墙体与湖泊碰撞、职业规则、候选推理和AI。
- `map_files.hpp`：本地地图加载、格式校验及临时文件保存后替换。
- `network.hpp` / `network.cpp`：地图协商、双人回合同步及赛后复盘。
- `lessons.hpp`：3×3推理课堂。

在此文件夹用 MinGW-w64 编译：

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Werror -pedantic -static -municode -mwindows app.cpp game.cpp network.cpp -lgdi32 -luser32 -lws2_32 -lcomdlg32 -o MistForest.exe
```

本次按精简流程验证：墙体与湖泊、冲刺和跟随碰撞、职业移除侦察、三格侦察保留、本地地图保存/加载/覆盖/错误保护、编辑器主要操作、对战及复盘，以及本机真实TCP双会话的地图同步与重赛。界面通过离屏绘制检查。没有重复大批量模拟，尚未进行异地两台实体电脑实测；系统文件选择窗口未做自动点击测试，其读写功能已直接验证。
