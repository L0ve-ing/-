# 雾隐之森 · 重骑与漩涡版（V5）

解压整个文件夹，双击 `MistForest.exe` 即可在 Windows 上运行。保留人机、本地双人、双人联机、地图 DIY 与赛后复盘。

## 这一版的变化

- 移除 AI 风格选择与推理教学，电脑使用统一策略。
- 推理辅助默认关闭，仍可在大厅手动开启。
- 放大对局中的攻击、移动、冲锋、确认按钮，以及对方职业与护甲。
- 职业版新增重骑；地图编辑器新增漩涡，可保存、加载和联机同步。
- 冲锋的路线、终点和步数不公开，只公开发动冲锋与伤害结果；完整路线在赛后复盘中查看。

## 地图与基本规则

| 模式 | 地图 | 规则 |
| --- | --- | --- |
| 3×3 侦察版 | 九格全可进入 | 每回合移动、攻击、侦察选一项；侦察无限次，无职业技能或护甲。 |
| 4×4 职业版 | 十六格全可进入 | 五职业，不提供侦察。 |
| 5×5 职业版 | 默认四角与中心为方墙，也可使用 DIY 地图 | 五职业，不提供侦察。 |

双方秘密选择起点，允许同格。职业在双方就绪后公开，位置隐藏。距离为水平格数与竖直格数之和；普通移动只能上下左右一步，也可选择原地等待。除重骑外，普通攻击可选自身格。攻击连线碰到方墙、线形墙的内部、边缘或端点都被挡住。

每位玩家提交一次完整行动，计为一个“回合”；双方各行动一次，计为一“轮”。80 回合仍未分胜负记为未决。重赛交换先手。

## 五种职业

| 职业 | 每回合能力 |
| --- | --- |
| 狙击手 | 移动一格或攻击一格；射程 3。 |
| 座狼 | 移动合计最多 2 步，并可攻击一次；射程 1，移动可分配在攻击前后。 |
| 白墨 | 可先普通移动 1 步再攻击一次，射程 1；另可在行动前或后冲刺恰好 2 步，随后两个自己的回合不可冲刺。冲刺逐步通过合法路径，不能穿墙或经过湖泊。 |
| 随影 | 移动一格、攻击射程 2 的一格、指定跟随三者选一；指定跟随占用本回合，在敌方下一回合自动复制移动，包括冲刺和冲锋。也可选择“移动带动”，自己的移动同步带动对方。复制遇到障碍或越界时跳过该步，并私下告知受影响玩家。 |
| 重骑 | 没有普通攻击。每回合选择普通移动最多 2 步，或单独发动 1–4 步冲锋；开局有 1 点护甲，可抵挡一次伤害，下一次伤害致命。 |

### 重骑冲锋

1. 选择“冲锋”，逐格点击相邻的合法目标。允许只前进 1 步后确认，最多 4 步。
2. 第一步确定方向；第一步走完后可以调整一次方向，不能向后折返，之后沿调整后的方向直行。
3. 第 1 步不造成伤害，第 2–4 步进入对手所在格时造成伤害。破甲后继续已选路线；致命命中立即结束对局，剩余计划不执行。
4. 普通移动与冲锋不能放在同一回合。冲锋不能穿过方墙、边墙、湖泊或地图边界。
5. 冲锋路线、终点、步数均隐藏。伤害与护甲结果公开，玩家仍可依据这些结果自行推测位置。

## 漩涡与地图 DIY

大厅进入“编辑 / 打开地图”。全部 25 格可修改，包括原有四角和中心；工具包括空地、方形墙、湖泊、漩涡、线形墙、橡皮擦和撤销。

| 地形 | 站立与移动 | 攻击 |
| --- | --- | --- |
| 空地 | 可进入 | 可穿过 |
| 方形墙 | 不可进入 | 阻挡 |
| 线形墙 | 阻挡跨边移动 | 阻挡 |
| 湖泊 | 不可进入 | 可穿过 |
| 漩涡 | 可进入 | 可穿过 |

漩涡在开局，以及每轮开始时，同时吸引上下左右相邻一格的双方角色。线形墙挡住吸引。邻接多个漩涡时，选择可达且格号最小者；一次结算只吸引一次，不连锁，也不造成伤害。本人收到自己的位移报告，对方不会直接收到你的起终点。

保存的 `.mistmap` 地图可在本地打开或分享。V5 可读取 V4 地图；包含漩涡的新地图需使用 V5。至少留下一个可站立格（空地或漩涡）。包内 `maps/漩涡林地.mistmap` 可直接打开体验。

## 操作与联机

选好动作类型后点击棋盘，将步骤依次加入计划。可撤销、清空，点击“确认本回合”才会执行。重骑冲锋时连续点击各步目标；若已安排普通移动，需要先清空才能改成冲锋。

本地双人使用遮罩交接视角；行动后先读自己的结果，再交给下一位。快捷键：A 攻击 / 重骑冲锋，M 移动，Z 撤销，Enter 确认；3×3 中 R / C 选择行列侦察，数字 1–9 选格。

双人联机中，房主选择地图并创建房间，另一方输入房主可达的 IPv4 地址和端口；默认端口 39091，地图自动同步。两人必须使用 V5（协议 6）。异地需要能互通的虚拟局域网或公网端口映射；此程序不自带中转服务器，地址框仍仅支持 IPv4，不直接解析域名。房主承担可信裁判，赛后才向对方提供完整回放。

结束后进入“对局复盘”，逐回合查看真实位置、完整冲锋路线、护甲与冷却。完整文字记录可导出到程序旁的 `replays` 文件夹。

## 源码与构建

`app.cpp` 为 Windows 界面，`game.hpp/.cpp` 为规则与电脑策略，`network.hpp/.cpp` 为 TCP 联机，`map_files.hpp` 为地图文件读写。源文件非空行保留中文注释。

使用 MinGW-w64 C++17，在本目录构建：

```powershell
g++ -std=c++17 -O2 -Wall -Wextra -Werror -pedantic -static -municode -mwindows app.cpp game.cpp network.cpp -lgdi32 -luser32 -lws2_32 -lcomdlg32 -o MistForest.exe
```

验证采用聚焦规则测试、界面交互及离屏渲染、实际本机 TCP 双会话检查。异地网络连通性需要双方在实际网络中验证。
