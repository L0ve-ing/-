# 雾隐之森：隐藏信息推理教学与联机对战系统

《雾隐之森》是基于 C++ 开发的九格隐藏位置策略游戏。它把人机对战、本地双人、双机联机、公开信息推理、三个教学关卡和赛后回放放在同一个 Windows 程序中，可作为大一年度项目的演示原型。本版新增双人联机，并将侦察改为可重复使用。

## 启动与环境

在 Windows 中双击同目录的 `MistForest.exe`。`NineGridStudio.exe` 是同步更新的兼容名称，功能相同，任选一个启动即可。程序使用 Windows 原生界面，不需要安装 Qt、浏览器服务器或额外游戏运行库。若自行修改源码，请按文末命令重新编译。

棋盘编号如下：

```text
1 2 3
4 5 6
7 8 9
```

## 基本规则

- 双方各秘密选择一个起始格，允许站在同一格。
- 双方轮流行动；每次行动选择移动、攻击或侦察。启用侦察时，使用次数不限。
- 移动必须向上下左右恰好走一格，不能斜走，也不能原地停留。
- 攻击可以选择自己所在格或上下左右相邻格，每次只攻击一个格子。命中即胜利，攻击不会移动角色。
- 对方能知道你是否移动、攻击了哪个格子；移动终点和角色真实位置不会公开。
- 单局最多执行 80 次双方合计的个人行动。达到上限仍未命中记为“未决”，不视为任一方获胜。
- 推理教学和统计用途中的“候选位置”是仍然可能的位置集合，不表示这些位置具有相同概率。

## 可重复使用的侦察

在开始页面选择“无限侦察”时，双方都可以在自己的任意回合使用侦察，没有次数限制；选择“原版”则关闭侦察。选择一整行或一整列，立即得知对方当前是否在该区域。每次侦察都消耗一个回合，随后轮到对方行动；侦察者不移动，也不会造成伤害。连续多个自己的回合都可以侦察，也可以反复侦察同一区域。侦察同样计入双方合计 80 次行动的单局上限。

侦察区域是公开信息，“有目标”或“无目标”的结果只显示给侦察者。在本规则下，被侦察者知道自己的位置，也能推知该结果；“结果私有”不意味着被侦察者无法推断。

如果对方随后移动，之前的侦察信息就需要结合一步移动重新更新，不能永久把侦察结果当作位置锁定。

## 对战模式

人机模式提供三种电脑风格。电脑依据自身位置和允许知道的信息决策，不会直接读取玩家的真实坐标。不同风格是用于体验和实验的策略，不保证最优：

- **主动攻击**：可攻击范围内有候选目标就射击，否则移动追近；不使用侦察。
- **隐蔽反击**：对方刚攻击、且自身能攻击候选目标时反击，否则移动避让；如果已确定唯一目标且能够命中，就会直接攻击，不必等对方开火。此策略不使用侦察。
- **灵活换位**：除优先攻击已确定目标外，连续两次攻击落空后会换位，也会在合适条件下使用侦察，兼顾新线索和移动机会。

本地双人模式需要两名玩家轮流使用同一台电脑。在另一人选择起始格或执行秘密操作时，请回避屏幕。行动后，当前玩家先阅读自己的结果，再点击“隐藏我的视角 · 交给下一位”；程序显示交接遮罩，下一位玩家确认后才打开其个人视角。侦察结果也按此流程交接。这个模式仍依赖双方遵守规则，不能阻止旁观、录像或读取程序内存。

练习时可以开启候选位置辅助，观察依据当前信息仍未排除的格子。它展示推理结果，不会显示对方的真实位置。关闭辅助后，可以只依靠行动历史进行推理。

本地模式中，“单局练习”只进行一局；“三局两胜”累计比分，先取得两场胜利的一方获胜。未决局不计分，因此包含未决时实际局数可能超过三局。每局结束后均交换先手，包括上一局未决的情况；每局重新选择起始位置，侦察版始终允许重复侦察。单局上限仍是双方合计 80 次行动。

## 双人联机

联机需要两台 Windows 电脑运行同一版本的程序。一人创建房间作为房主，另一人输入房主的 IPv4 地址加入。默认使用 TCP 端口 `39091`。

1. 两台电脑先接入同一局域网。房主在大厅选择“无限侦察”或“原版”，再点击“双人联机”，填写端口后点击“创建房间 · 等待朋友”。默认端口 `39091` 可保留；如被占用，可换一个端口。
2. 房主把页面“可分享的本机地址”中对应当前网络的 IPv4 地址及端口告诉对方，例如 `192.168.1.23`、`39091`。有多个地址时，选择双方所在局域网或虚拟局域网的地址。也可在 Windows“设置 → 网络和 Internet → 当前网络的属性”中查看。`127.0.0.1` 只适合同一台电脑上的测试。
3. 另一位玩家也进入“双人联机”，在“加入朋友的房间”区域填写房主地址，在左侧填写与房主相同的端口，点击“连接房主”。房主设置的规则会同步到加入者，不由双方分别设置。
4. 连接成功后，双方分别在自己的电脑上秘密选择起始格。房主是玩家 1，加入者是玩家 2；双方都确认起点后开始，首局由房主先手。
5. 按界面提示轮流移动、攻击或侦察。各自屏幕只显示自己的对战视角，无需像本地双人那样交接屏幕。
6. 联机目前按单局进行。结束后房主可以发起重赛，双方重新选择起点；每次重赛交换先手，包括上一局未决的情况。本地“三局两胜”仍可使用。

如 Windows 防火墙询问是否允许程序访问网络，可在可信的家庭或宿舍局域网中允许“专用网络”访问。无需关闭防火墙。无法连接时，先确认两端版本一致、房主仍在等待加入、IPv4 地址正确，以及 TCP 端口 `39091` 的访问没有被防火墙拦截。校园网、访客 Wi-Fi 或启用设备隔离的无线网络可能禁止设备互相连接，即使两人连着同名 Wi-Fi 也可能无法加入。

异地联机需要双方加入可互通的虚拟局域网，或使用可达的房主公网 IPv4 地址并配置相应端口转发和防火墙规则。该版本不提供云端房间匹配或自动穿透。路由器处于运营商共享地址环境时，单独配置本地端口转发可能仍不可达。

连接中断时，本局中止。需要重新连接并重新开局，暂不支持断线后接着原局继续；已经结束的本局复盘会保留供查看。

联机由房主程序担任可信裁判，负责保存完整局面并校验行动。加入者在对局过程中只接收自己的视角数据与允许公开的行动信息；完整位置和私有结果在对局结束后才用于复盘。房主本机内存仍包含完整状态，因此此设计适合可信朋友间对战，不保证抵御恶意房主读取或篡改内存。

## 三个教学关卡

在教学界面点击棋盘，选中所有认为可能的位置，再提交答案。点击已选格可以取消选择。答案要求集合完全一致：既不能漏选，也不能多选。

1. **攻击范围推理**：对方攻击 1 号格，位置候选为 1、2、4。
2. **一步移动更新**：从候选集合 1、2、4 分别向上下左右走一步，再合并所有终点，得到 1、2、3、4、5、7。
3. **多条证据结合**：你攻击 2 落空，接着对方攻击 1 且没有移动，因此从 1、2、4 中排除 2，剩下 1、4。

第二关中，新旧候选集合重叠并不意味着角色可以原地不动。例如，新集合中的 1 可以由旧集合中的 2 或 4 移入。

## 结束后的回放

完整位置回放只在对局结束后开放。回放从初始状态开始，保存每次有效行动后的快照，可用“上一步”“下一步”“起点”“结局”查看。界面展示双方真实位置，切换玩家按钮可分别查看两人当时的候选位置，便于核对各自的推理过程。对战进行中不开放这类全知视角。

复盘当前刚结束的一局时，可点击“返回本局结果”。本地系列赛保留比分，尚未分出胜负时可以选择“继续下一局”；联网房主可以选择“再来一局 · 交换先手”。房主发起重赛时，客人会进入新一局的起点选择，上一局复盘仍保留在记录中；新局进行中进入复盘会提示是否离开本局。

复盘时可以观察：攻击是否留下了明显线索、自己是否遗漏了未命中的排除信息，以及对手移动后是否仍误用旧位置判断。

回放页面可导出完整 UTF-8 文本记录，包括真实位置与侦察结果。文件保存到可执行程序旁的 `replays` 文件夹，以时间戳命名，便于保留多局实验记录。该记录属于赛后完整信息，不能当成对战过程中的公开日志。

## 项目用途与限制

本原型可以演示候选集合、集合排除、信息随时间变化，以及获取信息需要消耗行动的取舍。它也可作为不同策略、不同规则的实验基础。

它目前不能证明训练可以提高一般智力、现实决策能力或广泛迁移的推理能力。三个关卡的可理解性、侦察机制是否更有趣以及教学效果，都需要后续邀请同学试用并记录数据。

建议试用时同时记录是否完成教学、操作错误次数、相近推理题前后表现、再次游玩的意愿。对战实验应同时报告已决胜率、未决比例和对局长度，不能仅用剔除未决后的胜率评价策略。

## 源码与编译

- `app.cpp`：Windows 图形界面、操作交互、教学页面与回放展示。
- `game.hpp`、`game.cpp`：规则、游戏状态、候选位置更新和电脑策略。
- `network.hpp`、`network.cpp`：双人联机、消息传输与各玩家视角同步。
- `lessons.hpp`：三个教学关卡的文字与标准答案。

源码为 UTF-8；注释使用中文，说明 C++ 语法与相应代码的作用。教学中格子 1—9 在数组中对应下标 0—8。

在本目录使用支持 Windows 的 MinGW-w64 C++ 编译器执行：

```text
g++ -std=c++17 -O2 -Wall -Wextra -Werror -pedantic -static -finput-charset=UTF-8 -municode -mwindows app.cpp game.cpp network.cpp -lgdi32 -luser32 -lws2_32 -o MistForest.exe
```

`-std=c++17` 使用 C++17；`-Wall -Wextra -Werror -pedantic` 开启常见警告与标准检查，并将警告当作编译错误；`-municode` 选择宽字符入口；`-mwindows` 生成图形窗口程序；`-lgdi32` 和 `-luser32` 链接 Windows 绘图和窗口库；`-lws2_32` 链接联机使用的 Windows 网络库。此命令生成的是 Windows 程序，不能直接作为 macOS 或 Linux 可执行文件运行。若需要兼容旧名称，可将新生成的 `MistForest.exe` 另复制一份并命名为 `NineGridStudio.exe`。
