# 雾隐之森 · 历史项目展示

从九宫格控制台原型，到图形教学、双人联机与多地图职业对战。以下入口对应目前实际保存的程序、源码和研究报告。

## 可查看和运行的版本

| 阶段 | 主要内容 | 查看与运行 |
| --- | --- | --- |
| 九格暗战 · 控制台原型 | 3×3秘密选点、上下左右移动、攻击命中获胜；支持同机双人和基础人机。移动必须走一格，无侦察。 | [运行程序](hidden_grid.exe) · [C++源码](hidden_grid.cpp) · [使用说明](使用说明.md) |
| 雾隐之森 · 无限侦察联机版 | 3×3图形界面，保留原版与无限侦察模式；加入双人TCP联机、推理辅助、三个教学关卡、系列赛与赛后复盘。此版普通移动仍必须走一格。 | [完整版本包](雾隐之森_联机版.zip) · [使用说明](MistForest/使用说明.md) · [源码入口](MistForest/app.cpp) |
| 雾隐之森 · 四职业初版 | 增加5×5地图，只有中心13号格禁入；加入狙击手、座狼、白墨与随影，支持组合行动、两步冲刺和双向跟随。允许原地等待，移除无侦察模式。 | [历史版本包](雾隐之森_四职业版.zip) |
| 雾隐之森 · 多地图更新版 | 5×5四角与中心禁入，共20个可用格；新增全部16格可进入的4×4职业地图，支持人机、同机双人和联机。保留3×3无限侦察。 | [历史版本包](雾隐之森_四职业地图更新版.zip) · [使用说明](MistForestV3/使用说明.md) · [源码入口](MistForestV3/app.cpp) |
| 雾隐之森 · 地图 DIY 版 | 5×5地图可自由编辑方形墙、格边线形墙和湖泊，可本地保存、加载并联机同步；4×4与5×5职业对战移除侦察，3×3保留。 | [历史版本包](雾隐之森_地图DIY版.zip) · [使用说明](MistForestV4/使用说明.md) · [源码入口](MistForestV4/app.cpp) |
| 雾隐之森 · 重骑与漩涡版（当前） | 简化界面，移除 AI 风格与教学，默认关闭辅助推理；增加秘密冲锋、护甲与轮首漩涡吸引，支持五职业、DIY 保存和联机同步。 | [当前版本包](雾隐之森_重骑与漩涡版.zip) · [使用说明](MistForestV5/使用说明.md) · [源码入口](MistForestV5/app.cpp) |

运行历史图形版本时，请分别解压到不同文件夹，再打开其中的 `MistForest.exe`，避免同名程序混淆。联机双方须使用相同版本。

最早的图形教学阶段曾引入限次侦察和推理课堂，但目前未保留其独立可执行压缩包；功能介绍保存在[早期项目介绍](雾隐之森_项目介绍.md)中。现有 `NineGridStudio.zip` 与 `雾隐之森_联机版.zip` 内容完全相同，是兼容名称，不另算一个历史版本。`MistForestV3` 文件夹保留多地图更新版，四职业初版请使用对应历史压缩包；地图 DIY 版位于 `MistForestV4`，当前重骑与漩涡版位于 `MistForestV5`。

这些实验基于最初的3×3无侦察规则，不代表当前四职业地图的平衡性。
