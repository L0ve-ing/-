# -
雾隐之森（MistForest）**是一款基于 C++ 开发的隐藏位置回合制策略游戏。双方看不到对手的位置，需要通过公开行动和侦察结果推测目标，在隐藏自身、获取信息与主动攻击之间做出选择。一次准确的攻击，即可决定胜负。 项目从一个3×3九宫格对战原型逐步发展，现已支持多地图、四职业、人机对战、同机双人、TCP联机、推理教学与赛后复盘。
| 历史项目 | 主要特点 |
|---|---|
| 九格暗战 | 最初的3×3控制台游戏 |
| 策略研究 | 主动攻击、隐蔽反击等策略的模拟与分析 |
| 无限侦察联机版 | 图形界面、侦察、教学、双人联机和复盘 |
| 四职业初版 | 5×5中心禁入，加入四职业与组合行动 |
| 多地图更新版 | 5×5四角禁入，新增4×4地图 |
